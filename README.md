A Flappy Bird-inspired Game Boy game where you flip gravity to dodge pipes

## About

Gravi-flipper is a small arcade game made in C using GBDK. Instead of only moving in one direction, you can flip gravity to move between the top and bottom of the screen while avoiding pipes.

## Controls

| Button | Action |
|---|---|
| **START** | Start or restart the game |
| **A** | Flip gravity |

## Features

- Gravity-flipping gameplay
- Pipe obstacles with changing gaps
- Score counter
- Best-score counter
- Sound effects for flipping, scoring, and losing
- Title screen
- Game Over screen

## Built With

- C
- GBDK (Game Boy Development Kit)

## How to Play

1. Start the game.
2. Press **A** to flip gravity.
3. Avoid the pipes.
4. Pass through the gaps to earn points.
5. Try to beat your best score
